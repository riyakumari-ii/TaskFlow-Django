# TaskFlow - Django To-Do Web Application

## About
TaskFlow is a To-Do web application developed using Python and Django.

## Features
- Add tasks
- View tasks
- Manage tasks
- SQLite database

## Technologies
- Python
- Django
- HTML
- CSS
- SQLite

## How to Run

1. Install the requirements:
pip install -r requirements.txt

2. Run the server:
python manage.py runserver

3. Open:
http://127.0.0.1:8000/
